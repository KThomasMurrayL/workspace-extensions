Workspace Extensions

A growing collection of small extensions for planning, tracking, writing and working with data — everything saved as plain files in your own workspace.

Plain JavaScript·No dependencies·Data stays in your repo

Boards

Trello-style kanban boards without leaving the editor.

  • Lists (categories), cards and checklists, with progress on each card
  • Drag & drop cards between lists and reorder lists
  • Multiple boards, sidebar view and full editor tab
  • Saved to boards/boards.json in your workspace

Notes

A lightweight markdown note vault in your sidebar.

  • Notes tree, folders and daily notes
  • [[wiki links]] with autocomplete between notes
  • Upload images — copied to notes/assets/ and linked at the cursor
  • Saved to notes/ in your workspace

Flow

Flow charts for planning out a product or project.

  • Add nodes, drag them around, connect them with labelled arrows
  • Pan & zoom canvas, multiple flows
  • Copy any flow as a markdown outline for your plan or PR
  • Saved to flow/flow.json in your workspace

Database

View and edit databases without leaving the editor.

  • SQLite, PostgreSQL, MySQL/MariaDB and SQL Server connections
  • Open CSV, TSV and JSON files as editable tables
  • Grid editing with paging, plus a SQL console for queries
  • Connections saved to database/connections.json; passwords in VS Code's secure storage

Install

Download an extension, install it in VS Code, and you're done.

  1. Download a .vsix file

    Use the buttons above, or grab the files from GitHub Releases. The file lands in your Downloads folder.

  2. Install it in VS Code

    Open the Extensions view, click the … menu, and choose Install from VSIX… — or use the terminal:

    code --install-extension ~/Downloads/boards-0.2.0.vsix
code --install-extension ~/Downloads/notes-0.2.0.vsix
code --install-extension ~/Downloads/flow-0.1.1.vsix
code --install-extension ~/Downloads/database-0.1.0.vsix
  3. Reload and open a folder

    Run Developer: Reload Window from the Command Palette (⇧⌘P). The Boards, Notes, Flow and Database icons appear in the activity bar of any folder you open.

macOS tip: if the code command isn't set up, run "/Applications/Visual Studio Code.app/Contents/Resources/app/bin/code" instead.
